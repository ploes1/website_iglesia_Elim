# Sitio Web de la Iglesia Elim "Jesucristo te Ama"

Este sitio web tiene como función ser el sitio principal por el cual la Iglesia Elim "Jesucristo te Ama" se da a conocer y expande el mensaje del Evangelio con las puertas abiertas a todo el mundo.

## Características del sitio web

- Tiene múltiples secciones o páginas: la sección de Inicio, de Actividades, de Alabanzas, de Confesión de Fe y de Servicios.
- Tiene referencias a dos canales externos: el de YT y el de WhatsApp para darse a conocer de manera más extensa.
- Cuenta con un contador de visitantes en la sección de Inicio.
- Tiene un enfoque moderno: está diseñado basándose en modelos existentes de sitios web modernos de iglesias internacionales, para que se vea profesional y atractivo a todo el mundo.
